# C5 실내지도와 현재 위치

Refs #5. 기본 카메라는 기울기 0도의 평면이다. 지도 화면에는 층 선택 버튼만 표시한다. MapKit의 확대·이동·회전·기울임을 지원하며 층 전환에서 평면으로 맞춘다.

## 폴더 책임

- App: Root Store를 만들고 지도 Feature를 연결한다. 앱 전체 navigation은 이곳에 둔다.
- Features/IndoorMap: TCA 상태·행동, 지도 화면, MapKit overlay·annotation과 탭 처리를 담당한다.
- Domain/IndoorMap: 지도 요소·좌표·현재 위치, 도형 포함 관계와 샘플 유효성 규칙을 둔다. SwiftUI·MapKit·CoreLocation·TCA에 의존하지 않는다.
- Clients/IndoorMap: 번들 파일 로더와 IMDF DTO·Mapper, 테스트 가능한 지도 의존성을 둔다.
- Clients/Location: Core Location을 비동기 이벤트로 제공한다. Feature는 같은 인터페이스의 재생 위치로 교체할 수 있다.
- Resources: 로컬 C5 도면을 둔다. [가져오기와 라이선스](IndoorMapData.md)를 따른다.

기존 도메인 `IndoorMapFeature`는 지도 요소를 뜻하는 `IndoorMapElement`로 이름을 바꿨다. 사용자 행동 단위인 TCA `IndoorMapFeature`와 구분하기 위한 변경이다.

## 사용과 상태

1. 로컬 C5 데이터를 가져온 뒤 앱을 실행한다. 지도 초기 층은 수신된 위치의 ordinal에 해당하는 층이며, 위치가 없으면 도면의 첫 층이다.
2. 왼쪽 층 목록으로 보는 층을 바꾼다. 층 조회는 현재 위치의 층을 변경하지 않는다.
3. 도면·fixture·시설 마커를 표시한다. C5 fixture를 도서관 서가로 간주하지 않는다.
4. 현재 화면에서는 제목·현재 위치·전체 보기·하단 정보 패널·수동 지정 UI와 나침반·축척을 표시하지 않는다. 시설 선택과 길게 누르기로 수동 출발점을 만드는 동작도 화면에서 연결하지 않는다.
5. 이미 위치 권한이 있으면 지도 화면이 활성화된 동안 위치를 수신한다. 앱이 비활성화되거나 화면에서 나가면 스트림과 MapKit 사용자 위치 표시를 중지한다. 새 권한 요청을 실행하는 화면 버튼은 현재 표시하지 않는다.

위치 권한 요청·수동 현재 층/출발점·센서 복귀의 내부 action과 client는 후속 화면 연결을 위해 유지한다. 이 상태 전환은 테스트로 검증하지만 현재 화면에서 조작할 수 있는 기능으로 안내하지 않는다.

MapKit 카메라 요청은 `IndoorMapSurface`가 window에 붙고 유효한 크기로 배치된 뒤 적용한다. 배치 전 요청은 가장 최근 요청으로 보관하며, 실제 적용 후에만 완료로 기록한다. 동일한 요청이 반복되거나 layout이 다시 발생해도 사용자가 이동한 카메라를 덮어쓰지 않는다.

## 위치의 의미

- 실제 센서 모드의 Blue Dot은 MapKit 기본 사용자 위치 표시를 사용한다. 현재 층이 알려져 있고 조회 층과 다르면 Blue Dot을 숨긴다. 층 정보가 없을 때 좌표로 층을 추정하지 않는다.
- 위치 모델은 센서·수동·테스트 재생 소스를 구분한다. 수동·재생 위치를 연결하는 화면에서는 각각 보라색·주황색 마커를 사용하며 재생 위치를 실제 측위 결과로 표시하지 않는다.
- 센서 샘플은 유효한 WGS 84 좌표·0 이상의 유한한 horizontalAccuracy·현재 시각 대비 -5~30초 범위여야 수용한다. 더 오래된 순서 역전 샘플도 버린다. 이 시간 범위는 표시·중심 이동을 위한 초기 정책이며 도착 판정·C5 측위 정확도 보장이 아니다. 수동 위치에는 시간 만료를 적용하지 않는다.
- 위치를 저장하거나 별도 서버로 전송하는 기능, 백그라운드 위치 권한, Always 권한을 추가하지 않는다. MapKit·Core Location은 시스템 서비스를 사용한다.
- 권한은 Core Location의 권한 변경 콜백에서 읽어 캐시하고 새 구독자에게 캐시를 전달한다. 기기 전체 위치 서비스 OFF 구분은 denied 상태에서만 `@concurrent` 조회로 수행한다. 권한 철회는 조회를 기다리지 않고 먼저 전달하며, 취소되거나 이전 권한 상태에 대한 조회 결과는 반영하지 않는다. CLLocationManager 생성·delegate·업데이트 시작/중지는 MainActor에 유지한다.
- C5 층 연결은 `CLFloor.level`과 도면 ordinal의 일치로 처리한다. 실제 기기의 층 기준·정확도는 C5 현장에서 검증해야 한다. 없는 층을 임의로 첫 층에 매핑하지 않는다.

## 검증과 후속 범위

`IndoorMapTests`에서 도면 로딩·내부 ring·평면 카메라·초기 배치 전 카메라 보류와 적용·센서/수동 위치 전환·권한 거부와 철회·유효하지 않은 위치·위치 스트림 취소·재생 위치 구분을 검증한다. 시뮬레이터 검증으로 실제 실내 측위 품질을 대신하지 않는다.

지도 로딩 뒤 routing GeoJSON과 ShelfDirectory를 TCA의 navigation 상태에 읽는다. 데이터셋 해시·지도 층 참조와 목업 목적지 연결을 검증하며, 실패해도 지도·층 선택은 유지한다. [데이터 묶음과 사용 방법](IndoorNavigationData.md)을 참고한다.

도서 담당과 검색·추천 Feature 및 delegate 계약은 아직 정해지지 않았다. 도서 검색·추천·책 상세·장바구니·CV 화면과 홈 추천 child 연결, 길찾기 계산·경로 안내는 후속 범위다. 따라서 #5 전체 완료로 처리하지 않는다.
