# 책 상세 네이티브 시트

추천·검색·홈에서 같은 `BookDetailMapView`로 진입한다. 네이티브 시트 안에서 표지·서지정보·소개를 표시하고, 지도에서 선택한 책의 소장 서가를 강조한다.

## 화면 구성

- `BookDetailSheetPresenter`가 `UIHostingController<BookDetailSheet>`를 pageSheet로 표시한다. 초기 높이는 최대 detent 높이의 52%이며 큰 높이까지 확장할 수 있다. 기본 높이에서는 지도를 조작할 수 있다.
- 표지는 기존 `BookCoverView`로 시트 내부 헤더에 140×186pt 크기로 표시한다. 표지 오른쪽에 대출 상태 → 제목 → 층·실제 서가 번호 → 청구기호 → 거리·층 이동 횟수를 배치한다.
- 헤더 아래에 저자와 책 소개를 배치하고 본문을 스크롤한다. 큰 글자 접근성 크기나 VoiceOver에서는 전체 내용을 스크롤한다. 기존 DS 글꼴·행간·색상 토큰을 사용하며 글꼴은 접근성 크기에 대응한다.
- 찜은 지도 오른쪽 상단에 배치하고 기존 액션·저장소를 사용한다. VoiceOver에서는 제목의 접근성 액션으로도 찜을 변경할 수 있다.
- 안내·장바구니 버튼은 safeAreaInset으로 하단에 고정하고 기존 동작과 glass 버튼 스타일을 사용한다. 소장정보·소개 조회의 로딩·빈 결과·실패·재시도 및 Yes24 출처 링크를 유지한다.
- 시트 높이는 SwiftUI onGeometryChange에서 읽어 지도 하단 여백에 반영한다. 시트를 아래로 닫으면 이전 화면으로 돌아가고, 화면을 제거하면 상세에서 연 모달도 함께 닫는다.
- 별도 UIWindow, 표지 위치 추적용 CADisplayLink, 창 사이 좌표 변환과 돌출용 자리 표시는 사용하지 않는다.

## 시트 재질

네이티브 시트의 기본 Liquid Glass를 사용한다. 호스팅 뷰는 clear로 설정하고, 상세 루트에 `containerBackground(.clear, for: .navigation)`을 적용한다. 커스텀 UIBlurEffect와 본문의 추가 색상 배경은 제거했다. 모서리 반경은 28pt이고 grabber는 숨긴다.

Apple 설명에 따르면 iOS 26의 부분 높이 시트는 Liquid Glass를 사용하며 전체 높이로 확장되면서 더 불투명해진다. [WWDC25: Build a SwiftUI app with the new design](https://developer.apple.com/videos/play/wwdc2025/323/)

## 소장본·서가·경로 연결

- 대표 소장본은 기존 `BookHoldingPresentation.preferred`로 선택한다. 그 소장본의 위치·청구기호에 매칭된 서가만 표시·탐색해 다른 소장처의 대출 상태나 청구기호를 섞지 않는다.
- 서가 번호는 fixture 식별자가 아닌 실제 표시 번호를 사용한다. 복수 후보를 보존하며, 경로 계산에는 기존 ShelfOverlapPolicy가 허용하는 범위만 사용한다.
- 한 층으로 매칭되면 그 층을 지도에 표시하고 매칭된 서가를 강조한다.
- 현재 지도 Store의 도면·서가·경로 자료·위치·경로 선호도를 전달하고, 기존 IndoorRouteClient로 현재 위치에서 후보 서가까지 계산한다. 상세 계산은 공용 지도에 저장된 경로를 덮어쓰지 않는다.
- 유효한 위치·서가 도착 노드·경로 자료가 없으면 거리를 확인 불가로 표시한다. 층 이동 횟수는 경로의 floorChanges 개수이고, 예상 거리에는 `약`을 붙인다. 디자인의 310m·0회는 고정하지 않았다.
- 요청 번호와 취소 ID로 이전 위치·소장본의 늦은 경로 응답을 배제한다. 상세 데이터 효과는 TCA 상세 상태의 수명에 연결한다.

## 디자인 결정 이력

사용자가 제공한 `4-1-1. 층 이동 없을 때 상세 정보.png`를 기준으로 정보 순서와 하단 버튼을 재배치했다. 표지 돌출을 검토·구현했으나 UI 피드백에 따라 제거했고, 최종 구현은 시트 내부 배치다. 초기 돌출 전용 배치 모델과 테스트도 제거했다.

반투명 시트에 대한 피드백 이후 기본 재질을 가릴 수 있는 배경 설정을 제거했다. 런타임 뷰 계층은 확인하지 못했으므로 당시 화면의 원인과 수정 후 시각적 결과는 확정하지 않았다.

## 남은 실행 확인

1. 추천·검색·홈에서 책을 열어 표지와 정보가 시트 안에 배치되고 안내·장바구니 버튼이 하단에 유지되는지 확인한다.
2. 기본·큰 높이 사이에서 재질 전환과 지도 하단 여백을 확인한다.
3. 시트 닫기·뒤로가기·경로 미리보기·서가 지도·알림의 표시와 복귀를 확인한다.
4. 표지 재시도, 소장정보·소개의 빈 결과·실패·재시도를 확인한다.
5. 큰 글자·VoiceOver와 실제 소장 서가·거리·층 이동 정보를 확인한다.
