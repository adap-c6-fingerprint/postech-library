# 지도 배경 다크모드

관련 이슈: [#228](https://github.com/adap-c6-fingerprint/postech-library/issues/228)

## 적용 색상

| 대상 | 색상 | 도면 분류 |
| --- | --- | --- |
| 층 바닥·구역 바닥 | `#353535` | 층 외곽, 일반 unit, section |
| 책상·서가 | `#555555` | fixture의 `desk`, `furniture` |
| 벽면 | `#595959` | unit의 `structure`와 fixture의 `wall` |
| 계단·엘리베이터 | `#545454` | unit의 `stairs`, `stairway`, `elevator` |
| 통로 | `#202020` | unit의 `walkway` 중 5층 엘리베이터 앞 홀을 제외한 19곳 |
| 5층 엘리베이터 앞 홀 | `#353535`, 테두리 없음 | 원본 분류는 `walkway`지만 사용자 지정에서 제외한 구역 |
| 가운데 빈 공간 | `#202020` | unit의 `opentobelow`(3·4·5층) |
| 비공개 공간 | `#545454` | unit의 `nonpublic` 13곳 |
| 출입문 | `#626262` | opening 254개의 선 색상 |
| 화장실 | `#555555` | unit의 `restroom.*` 20곳(여자 8·남자 8·장애인 4) |
| 5층 릴렉스존 | `#202020` | 5층(ordinal 4)의 `lounge` 중 이름이 `Relax Zone`인 구역 |
| 게임존 | `#202020` | unit의 `recreation`(도면 이름 `게임룸`, 5층 1곳) |
| 벽과 도면의 경계선 | `#1D1D1D` | 출입문과 5층 엘리베이터 앞 홀을 제외한 도면 도형의 테두리 |

모든 지도 화면에서 같은 기본 색상을 사용하고 지도 자체의 배경은 다크모드로 표시한다. 경로·목적지·선택 강조색은 기존 표시를 유지한다. 원본 도면·위치·길찾기 자료와 어노테이션 에셋은 변경하지 않는다.

5층 엘리베이터 앞 홀은 원본 도면에서 `walkway`로 분류되어 있다. 두 엘리베이터에 맞닿은 해당 구역(`732c6ee7-1021-443c-a020-a3ce41460653`)만 기본 바닥색으로 표시하고 테두리 선을 숨긴다. 도면 분류와 길찾기 자료는 변경하지 않는다.

층 선택은 스크롤 없이 모든 층을 위층부터 한 번에 표시한다. 각 버튼은 최소 44pt 높이를 확보하고 전체 층 수에 맞춰 스택 높이가 늘어난다. 홈에서는 층 선택 스택과 현재 위치 버튼의 하단 정렬을 유지한다.

## 별도 색상이 지정되지 않은 unit

아래 구역의 바닥에는 공통 바닥색 `#353535`를 사용한다. 용도별 별도 색상은 지정되지 않았다. 개수는 앱에 포함된 POSTECH 도서관 도면 기준이다.

| 구역 | 분류 | 개수 |
| --- | --- | --- |
| 카페 니어미 | `foodservice` | 1 |
| 편의점 | `unspecified` | 1 |
| 1층 휴게공간 | `lounge` | 1 |
| 일반실(GSR·미팅룸·회의실·스튜디오 등) | `room` | 95 |
| 창고 | `storage` | 16 |
| 테라스 | `terrace` | 2 |
| 로비 | `lobby` | 1 |
| 사무실 | `office` | 2 |
| 도서관 구역 | `library` | 5 |
| 강의실 | `classroom` | 4 |

추가로 fixture의 장비(`equipment`) 14개와 장애물(`obstruction`) 1개는 채움색을 지정하지 않아 기존 색을 유지한다. 경계선은 공통 `#1D1D1D`를 사용한다. `furniture`는 도면에서 책상·서가 등을 세분하지 않는 분류이므로 같은 색으로 표시한다.

## 확인 결과

- 최신 `dev`의 `4d50a6a`에서 `feat/#228-map-dark-background` 브랜치를 만들었다.
- 출입문·화장실 색상 추가 전 기존 지도 관련 검사 15개가 통과했다. 3·4층의 서가가 첫 화면에 새 회색으로 표시되는 것을 실제 화면 픽셀로 확인하고, 서가 강조·홈 어노테이션·사용자 위치·길안내 카메라 동작을 함께 확인했다.
- 출입문 254개·화장실 20곳과 5층 릴렉스존·게임존의 색상을 적용한 뒤 iOS 시뮬레이터 빌드가 성공했다.
- 층 선택 스크롤 제거와 5층 엘리베이터 앞 홀 색상 보정 후 기존 지도·층 선택·초기 배치 검사 24개가 통과했다. 실제 홈 화면 이미지에서 1~5층이 모두 보이고 현재 위치 버튼과 하단이 정렬되는 것을 확인했다.
- 5층 엘리베이터 앞 홀의 테두리 선을 숨긴 최종 상태에서 iOS 시뮬레이터 빌드와 지도 관련 검사 24개(9개 묶음)가 모두 통과했다. 서가의 첫 화면 표시, 층 전환과 카메라 유지, 책 위치 강조, 홈 아이콘·사용자 위치, 길안내 확대를 확인한 결과이며 전체 앱 검사는 포함하지 않는다.
- 개인 서명 설정·별도 도서 상세 주석·비밀 설정·이미지 파일은 보존했다.
