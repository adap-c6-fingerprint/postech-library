# 확대에 따른 서가 레이블

관련 이슈: [#268](https://github.com/adap-c6-fingerprint/postech-library/issues/268)

## 표시 단계

| 지도 상태 | 표시 내용 |
| --- | --- |
| 축소 | 가까운 서가 묶음의 가운데에 `301~310` 같은 범위를 두 줄로 표시 |
| 중간 확대 | 같은 실제 서가의 A/B를 합쳐 `310` 한 개 표시 |
| 상세 확대 | `310-A`, `310-B` 표시. 면의 폭이 작다는 이유로 표시를 늦추지 않음 |

기존 카드 배경·테두리·청구기호 범위는 지도에서 제거한다. 밝은 글자와 얇은 어두운 외곽선만 사용한다. 축소 군집은 화면 기준 수평을 유지하고, 중간 번호와 최대 확대 A/B는 서가 방향을 따르되 거꾸로 뒤집히지 않는다. 홈·책 위치·경로 미리보기·길안내가 같은 표시 코드를 사용한다.

세 단계 모두 `DS.Typography.caption1`의 폰트·행간·자간을 사용한다. 글자 겹침을 계산할 때도 같은 설정으로 크기를 측정한다.

## 묶음과 위치

- 번호가 같은 모든 도형을 합치지 않는다. 같은 층·같은 fixture의 A/B만 하나의 실제 서가로 묶는다.
- 축소 군집은 같은 층에서 중심 간 거리가 2.8m 이내인 이웃 서가를 연결해서 만든다. 10개 번호 단위로 자르지 않는다. 실제 3층 자료의 `301~310`도 하나의 묶음이 된다.
- 군집 위치는 구성 서가 중심의 평균이다. 군집 범위는 실제 구성원의 번호로 계산하며, 숫자와 `499A` 같은 번호가 섞이면 구분해서 표시한다.
- 각 면의 실제 꼭짓점에서 바깥 시작 모서리를 기준점으로 고른다. A/B는 서가 길이의 서로 반대쪽 끝에서 시작하며, 지도 회전으로 기준 모서리를 바꾸지 않는다.
- 기준점에서 길이 방향으로 `24pt + 글자 너비/2`만큼 안쪽에 글자 중심을 둔다. 짧은 면에서는 길이 중앙을 넘지 않는다. 이전 6pt보다 양 끝 여백을 늘렸다.
- 너비 방향은 해당 구간의 실제 바깥 변에서 여백을 재며, 좁은 면에서도 글자 중심을 자기 면 안에 둔다. 글자 전체가 면에 들어가야 한다는 표시 제한은 제거했다.
- 각 레이블에는 표시 위치가 하나만 있다. 화면 밖으로 나가거나 하트·시설과 겹쳐도 다른 자리로 옮기지 않는다. 군집 번호는 구성 서가 중심의 평균 좌표에 고정한다.
- 찜·편의시설은 원래 좌표를 유지하며 서가 레이블보다 높은 표시 순서로 그린다. 두 종류 사이의 겹침 검사는 하지 않는다.
- 찜·계단·엘리베이터는 편의시설 버튼을 꺼도 현재 층에 계속 표시한다. 편의점은 편의시설 버튼을 켰을 때만 표시한다.
- 찜·편의시설과 길안내의 층간 이동 이미지 아이콘은 공통 크기 30×30pt로 표시한다. 대체 시설 아이콘도 같은 크기를 사용한다.
- 레이블끼리 겹쳐도 재배치하거나 숨기지 않는다. 화면 밖의 레이블은 원래 위치에 두고 화면에 걸친 부분만 그린다. 원본 도형과 길찾기에서 쓰는 실제 좌표는 유지한다.

## 확대 기준

화면 1pt가 지도에서 몇 m인지 측정한다. 기본 경계는 군집↔번호 0.10m/pt, 번호↔A/B 0.055m/pt다. 경계에서 조금 확대·축소할 때 반복 전환되지 않도록 군집은 0.09~0.11m/pt, 면은 0.05~0.06m/pt 구간에서 이전 상태를 유지한다. 면 크기 검사 때문에 A/B 전환을 더 늦추지 않는다.

좁은 면까지 확대해서 볼 수 있도록 카메라의 최소 거리 제한을 25m에서 5m로 조정했다.

범위·글자 크기·군집 거리는 표시 정책이며 실기기와 디자인 확인을 거쳐 조정할 수 있다.

## 보존하는 정보

원본 308개 면과 청구기호·층·도형 식별자는 변경하지 않는다. 표시용 번호는 154개 실물 서가로 합쳐지지만 소장 위치 판정과 길찾기는 계속 원본 면을 사용한다. 실제 서가 번호의 일부인 `499A`는 중간 단계에서도 유지한다. 도면·서가 JSON·경로 그래프·사진 촬영 순서는 수정하지 않는다.

## 확인 결과

- iOS 시뮬레이터에서 관련 검사 20개, 11개 묶음이 통과했다.
- 실제 도서관 지도에서 군집·번호·면 단계의 화면 이미지를 저장하고 확인했다.
- 3·4층 표시, 면 합치기와 원본 보존, 고정 위치와 하트·번호 동시 표시, 서가 강조와 재진입, 첫 도면 표시, 사용자 위치 및 길안내 카메라를 검사했다.
- 303·335·313 서가의 0°·55° 지도 회전, 0.025m/pt에서 A/B 표시, 화면 밖 레이블 유지, 지도 이동 후 표시 좌표 고정을 확인했다.
- 시설 아이콘이 군집 중심과 겹쳐도 번호 위치가 이동하지 않고 아이콘이 위에 표시되는 것을 확인했다.
- 기본 아이콘 표시 변경 후 관련 검사 12개가 통과했다. 버튼 켜기·끄기, 찜 취소, 현재 층 표시와 외부 조회가 발생하지 않는 동작을 확인했다.
- 전체 앱 검사와 실기기 보행 검증은 포함하지 않는다.
