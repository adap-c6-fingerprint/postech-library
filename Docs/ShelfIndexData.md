## 필드의 역할

| 필드 | 확인한 의미·처리 원칙 |
| --- | --- |
| `fixtureNumber` | IM-DFrnt에서 태깅한 `S-층정보-고유번호-사이드` 식별자. 현재 IMDF fixture 이름과 정확히 연결한다. |
| `floor` | `3F`, `4F` 같은 표시 층. 실제 IMDF 층 참조와 대조한다. |
| `realNumber` | 현장 서가 번호. `499A`, `499G`도 있어 문자열로 보존한다. A·B 면에서 같은 번호를 쓰므로 단독 식별자로 쓰지 않는다. |
| `side` | 아트리움을 등졌을 때 왼쪽은 A, 오른쪽은 B. 기기 방향이나 지도 북쪽을 기준으로 다시 해석하지 않는다. |
| `sequence` | 사진 촬영 순서. 원본 정수로 보존하며 방문 순서·경로 비용·서가 연결 우선순위로 쓰지 않는다. |
| `other` | 청구기호가 없는 경우의 기타 분류. 예: 영어교재, 참고도서, 학위논문. |
| `callStart` | 청구기호 범위 시작. |
| `callEnd` | 청구기호 범위 끝. |
| `classStart` | 분류기호 범위 시작. |
| `classEnd` | 분류기호 범위 끝. |

## 지도 표시

`BundledShelfLabelLoader`는 중복 fixtureNumber, 일치하지 않는 도형·층·면, 부분 범위와 잘못된
필드 형식을 거부한다. 308개는 현재 IMDF의 unit이 아닌 **fixture** 이름에 연결된다.
`IndoorMapFeature`는 레이블 로딩·실패·재시도·취소를 길찾기 자료와 독립적으로 관리한다.
실패해도 지도와 층 선택은 유지한다.

현재 층의 각 면에 실제 서가 번호와 A/B를 `301-A`처럼 표시하고 아래에 `AC1.G72 ~ AM79.K8`을
보여준다. 기타 분류는 그 이름을, 빈 서가는 `빈 서가`를 표시한다. 도형 중심에 고정한 레이블이므로
층 전환이나 위치 수신으로 카메라를 옮기지 않는다. 화면 중심에 가까운 레이블부터 겹치지 않게 배치하고,
지도를 이동·확대하면 다시 배치한다.
촬영 순서나 도형 중심을 방문 순서·길찾기 도착점으로 사용하지 않는다.

## 확정한 범위 방향과 확인 대기 항목

2026-10-27 사용자가 가이드 표의 시작·끝 설명이 뒤바뀐 오기임을 확인했다.
키 이름대로 `callStart`·`classStart`가 시작이고 `callEnd`·`classEnd`가 끝이다.
예를 들어 `callStart: AC1.G72`, `callEnd: AM79.K8`은 AC1.G72부터 AM79.K8까지의 범위를 뜻한다.

인접 항목의 `callEnd`와 다음 `callStart`가 같은 경우도 53곳 있다. 예를 들어 `AM79.K8`이 두 서가에
함께 등장한다. 경계값의 포함 범위와 실제 도서의 전체 청구기호를 비교하는 규칙은 아직 확인 대기다.
촬영 순서나 배열 순서를 이용해 첫 후보를 임의로 선택하지 않는다.
