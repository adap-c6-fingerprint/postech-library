# 실시간 안내 위치 진단 기록 사용법 (실험 브랜치 전용)

`feat/navigation-location-diagnostics` 브랜치에만 있는 기능이다. `dev`에 올리지 않는다.
실시간 길안내 중 blue dot 튐을 수치·궤적·화면 녹화로 기록하고 내보낸다.

## 1. 준비

1. 이 브랜치를 Xcode에서 **Debug**로 **iOS 27 실제 iPhone**에 설치한다. (진단 버튼은 Debug 빌드에만 보인다.)
2. 위치 권한: 앱 사용 중 허용 + **정확한 위치 켜기**.
3. 처음 기록할 때 뜨는 **동작 및 피트니스** 권한을 허용한다. (걸음 수·정지 여부 기록)
4. Wi-Fi를 켠다. Apple 실내측위는 Wi-Fi 신호를 쓴다.

## 2. 자동 측정 모드 (`/test`, 권장)

QA·데이터 확보용으로 조작 없이 기록한다.

1. 검색 탭 검색창에 `/test`를 입력하고 검색한다. "측정 모드를 켰어요" 알림이 뜬다. 앱을 다시 켜도 유지된다.
2. 이후 길안내를 시작할 때마다 기록이 **자동으로 시작**되고, 안내를 끝내면 **자동으로 저장**된다. HUD에 `AUTO REC`가 보인다.
3. 화면 녹화는 하지 않는다(시스템 승인 창이 필요해서). 영상이 필요하면 아래 수동 기록을 쓴다.
4. 튐 표시와 기준점은 선택이다. 걸으면서 필요할 때만 누른다.
5. 끄려면 검색창에 `/test`를 다시 입력하거나, 안내 화면의 진단 버튼 → **측정 모드 끄기**. 끄면 진행 중인 기록은 바로 저장된다.
6. 측정 모드가 켜져 있으면 Release 빌드에서도 진단 버튼이 보여서 기록 목록·내보내기를 쓸 수 있다.
7. 안내 화면이 열리는 순간 잠깐 생기는 3초 미만 자동 기록은 저장하지 않는다.

## 2-1. 수동 기록

자동 측정 모드가 꺼져 있을 때 쓴다. 화면 녹화가 필요하면 이 방법을 쓴다.

1. 책 상세 → **바로 안내 시작**으로 실시간 안내에 들어간다.
   - **출발 위치 직접 설정**을 쓰면 센서 위치로 안내하지 않으므로 안내 판정 기록이 남지 않는다. 센서 위치로 시작한다.
2. 안내 화면 오른쪽 위 **파형 버튼**(✕ 왼쪽)을 누른다.
3. 기기 자세(손에 들고 화면 보기 / 주머니·가방 / 기타)를 고른다.
4. 필요하면 **화면 녹화**와 **음성 메모(마이크)**를 켠다.
5. **기록 시작** → 화면 녹화를 켰다면 시스템 화면에서 앱 화면 녹화를 허용한다.
6. 화면에 빨간 `REC` HUD가 뜨면 기록 중이다. 버튼이 빨간 원으로 바뀐다.

## 3. 걸으면서 할 일

| 상황 | 조작 |
|---|---|
| 점이 튀었다고 느낌 | HUD의 **튐!** |
| 실제 위치를 남기고 싶음 | HUD의 **기준점** → 지도를 움직여 노란 십자선을 지금 서 있는 곳에 맞춤 → **여기예요** |
| 목적지 서가 앞에 도착 | 진단 버튼 → **목적지 서가 앞에 서 있어요** |

- 마커를 누르면 HUD 테두리가 깜빡인다. 화면 녹화에서도 그 시점을 찾을 수 있다.
- HUD 시계(밀리초)는 영상과 기록의 시점이 맞는지 확인하는 용도다.
- 기준점의 지도 중앙 좌표는 지도를 한 번 움직여야 잡힌다. 움직이기 전에는 **여기예요**가 꺼져 있다.

## 4. 측정 절차 (권장)

1. **정지**: 층마다 위치를 아는 지점 3곳에서 기준점을 찍고 60초 서 있는다.
2. **보행**: 정해 둔 경로를 평소 속도로 걷고, 모퉁이·통로 끝을 지날 때마다 기준점을 찍는다. 두 기준점 사이는 일정 속도로 걸었다고 보고 정답 위치를 보간한다.
3. **층 이동**: 계단·엘리베이터 구간을 포함한다.
4. 같은 경로를 **3회 이상** 반복하고, 가능하면 기기 2종 이상으로 측정한다.

## 5. 기록 종료

- 진단 버튼 → **기록 종료**, 또는 안내를 종료하거나 화면을 닫으면 자동으로 저장하고 끝난다.
- 앱이 중간에 종료돼도 기록은 남는다. 다음에 기록 목록을 열면 요약을 다시 만든다.

## 6. 내보내기

- 진단 버튼 → **기록 목록·내보내기** → 세션의 **내보내기** → AirDrop으로 Mac에 보내거나 **파일에 저장**.
- 또는 **파일 앱 › 나의 iPhone › Po:book › LocationDiagnostics**에서 폴더째 복사한다.
- 또는 Mac Finder에서 iPhone 선택 → 파일 → Po:book.
- 목록에서 왼쪽으로 밀어 세션을 삭제할 수 있다.

## 7. 파일

세션 폴더 이름은 시작 시각(`yyyyMMdd-HHmmss`)이다.

| 파일 | 내용 |
|---|---|
| `session.jsonl` | 한 줄에 기록 하나. `type`: `location`(원본 측위), `heading`, `guidance`(앱 판정·표시 위치·경로 투영점·진행 거리), `motion`(걸음), `activity`(정지·보행), `marker`, `event`, `route`(안내 경로) |
| `summary.json` | 요약 지표 |
| `meta.json` | 기기·iOS·앱 버전, 자세, 안내 임계값, 화면 녹화 시작 시각 |
| `track.geojson` | 원본 궤적·표시 궤적·경로·마커. [geojson.io](https://geojson.io) 또는 QGIS로 연다 |
| `screen.mp4` | 앱 화면 녹화(켠 경우) |

### summary.json 주요 지표

| 지표 | 뜻 |
|---|---|
| `horizontalAccuracy` | 기기가 보고한 오차(m)의 중앙값·p90·최대 |
| `jumpCount`, `jumpsPerMinute` | 1.5m 이상이면서 2.5m/s를 넘는 이동 횟수 |
| `stationaryJumpCount`, `stationarySpreadMeters` | 정지 중 튐 횟수, 10초 이상 정지 구간의 흩어짐(RMS) |
| `checkpointErrorMeters`, `walkingErrorMeters` | 기준점 대비 실제 오차, 기준점 사이 보간 정답 대비 보행 오차 |
| `maneuverFlipCount` | 10초 안에 회전 안내가 A→B→A로 뒤집힌 횟수 |
| `remainingIncreaseCount`, `progressRegressionCount/Meters` | 남은 거리 증가, 진행 거리 역행 |
| `guidanceQualityRatio`, `guidanceSuspensionCount` | 안내 판정별 시간 비율, on_route에서 벗어난 횟수 |
| `distanceToRouteMeters`, `cameraRecenterCount` | 경로까지 거리, 카메라 재조정 횟수 |

### 영상과 기록 맞추기

`meta.json`의 `screenRecordingStartedAt`이 영상 0초다. 기록의 시각에서 이 값을 빼면 영상 위치(초)가 된다.

## 8. 주의

- 기록에는 정확한 위치가 들어 있다. 내보낸 파일을 저장소에 커밋하지 않는다(`LocationDiagnostics/`는 `.gitignore`에 있다).
- 화면 녹화(ScreenCaptureKit)와 걸음 기록은 시뮬레이터에서 확인할 수 없어 실제 기기에서 처음 확인해야 한다.
